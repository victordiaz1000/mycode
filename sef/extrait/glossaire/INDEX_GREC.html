INDEX DES MOTS GRECS

Relevé des mots étudiés dans le glossaire ou signalés dans les notes ou dans l'introduction (PENTATEUQUE).

Par ailleurs, un assez grand nombre de ces mots, présents également dans le Nouveau Testament, font l'objet de liens permettant d'explorer l'usage qui en est fait. Dans quelques rares cas, un mot du même champ sémantique pourra être pointé, comme par exemple un adjectif (γνωστός, "qu'on peut connaître, connu") pour un adverbe (γνωστῶς, "de façon à être connu, clairement, distinctement").
