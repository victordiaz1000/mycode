Installer l'APK hors Play Store

Android bloque par défaut l'installation de sources inconnues — voici les étapes.

  1. Téléchargez le fichier APK via le bouton ci-dessus.
  2. Quand Chrome vous prévient « fichier potentiellement dangereux », choisissez « Télécharger quand même » (l'APK vient de GitHub Releases).
  3. Ouvrez le fichier téléchargé. Android vous demande d'autoriser l'installation depuis votre navigateur : activez « Autoriser cette source ».
  4. Validez l'installation. BYM apparaît dans vos applications.

L'APK est signé avec la clé personnelle de l'auteur ; les mises à jour écrasent l'ancienne version sans perte de données.
