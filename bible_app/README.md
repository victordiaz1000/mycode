# BYM Classic — Bible de Yehoshoua Ha Mashiah

> Application Android de lecture **et** d'étude biblique : le texte intégral de la
> BYM, une quinzaine de traductions, le lexique Strong hébreu/grec, les
> interlinéaires, notes et surlignages, 14 thèmes de lecture — le tout

## Ce que fait l'app

### Lecture

- **Plusieurs onglets** — on autant de passages ouverts que voulu, comme dans un
  navigateur : onglets de lecture, page « nouvel onglet », onglets d'ouvrages,
  groupes colorés, et la position de lecture est restaurée à l'ouverture.
- **Navigation au doigt** — chapitre précédent / suivant au swipe dans les deux
  sens, ou d'un tap sur les chevrons ‹ › de la barre d'actions.
- **Lecture parallèle** — deux traductions côte à côte, alignées verset par
  verset.
- **Comparateur de versions** — le même verset dans toutes les versions
  installées, sur un seul écran.
- **Téléphone comme tablette** — interface adaptée aux petits et grands écrans,
  portrait comme paysage, barre de navigation adaptative et mode immersion.

### Étude biblique

- **Lexique Strong intégré** — 14 195 entrées hébreu / grec : lemmes,
  translittération, prononciation, catégories grammaticales et définitions
  complètes en français.
- **Lecture mot à mot** — un tap sur un mot du verset ouvre sa fiche Strong
  complète ; on parcourt ensuite mot précédent / mot suivant sans quitter la
  lecture.
- **Étude du verset** — écran combiné *Lexique & Dictionnaire* : le verset est
  rendu mot à mot, chaque mot porteur d'un numéro Strong ouvre sa fiche, chaque
  mot définit par un dictionnaire ouvre l'article (Westphal embarqué ou
  dictionnaire téléchargé).
- **Occurrences** — pour un numéro Strong donné, la liste livre par livre des
  versets qui le portent, avec le mot mis en évidence dans son contexte.
- **Interlinéaires** — source ATI (hébreu, Ancien Testament) et NTI (grec,
  Nouveau Testament) : glose, analyse grammaticale, numéro Strong et renvois,
  avec des couleurs distinctes pour suivre chaque couche de lecture.
- **Notes BYM en ligne** — les 5 753 notes du texte BYM s'affichent sous le
  verset auquel elles se rattachent, avec renvois croisés navigables.
- **Recherche unifiée** — passages, notes, études, Strong et dictionnaire dans
  le même champ, avec reconnaissance des références (« Jean 3:16 »), filtres
  (version, section, livre) et classement exact > préfixe > sous-chaîne.

### Organisation personnelle

- **Notes** — notes multiples par verset, éditables et exportables.
- **Surlignage** — sélection multiple de versets, 16 couleurs.
- **Favoris** et **historique** de lecture — rangés localement, jamais envoyés
  nulle part.
- **Partage** — un verset ou une étude se partage au format texte.

### Confort de lecture

- **14 thèmes** — parchemin, papier clair, mosaïque, bois doré, cacao, brume,
  acier, sable minéral, azur, nuit étoilée, Sinaï, lin blanc, veillée… et
  **photo personnelle** en fond d'écran.
- **12 familles de caractères** — dont Lora, Literata, EB Garamond, Cardo et
  Gentium Plus pour l'hébreu et le grec.
- **Réglages fins** — taille, graisse, aération, alignement, marges
  latérales, couleur du texte, disposition des notes, opacité du panneau : tout
  se règle depuis l'écran des paramètres.

### Bibliothèque

- **Ouvrages d'édification** téléchargeables et lus dans l'app : *Le Ministère
  ou le Seigneur*, *L'Animalité de l'être humain*, *Le Châtiment du Père*,
  *De l'ombre à la lumière*, *La Croix*, *Le Nom du Père*, *Les Voleurs de
  temps*.
- **Dictionnaires** — Dictionnaire Strong français et *Westphal 1932*
  (dictionnaire encyclopédique) embarqués, *Glossaire Martin 1744*
  téléchargeable ; Nave à venir.
- **Lexique BYM** — index alphabétique complet, avec recherche et pastilles de
  lettres (accents repliés : « Éternel » se trouve sous « E »).

### Hors ligne et mise à jour du texte

- **100 % hors ligne** — textes bibliques, lexique et dictionnaires sont
  embarqués dans l'APK : lecture, étude et recherche fonctionnent sans aucune
  connexion.
- **Mises à jour du texte BYM** — les corrections publiées à la source sont
  vérifiées (empreinte de blob git contrôlée à la réception) puis
  téléchargées livre par livre, avec votre accord ; le texte corrigé prend la
  priorité sur l'asset embarqué, sans réinstaller l'app.
- **Versions téléchargeables à la demande** — LSG 1910, Darby, Martin, KJV,
  Ostervald, néo-crampon, Chouraqui, la Septante (grec)… le catalogue est
  configurable, l'app ne télécharge que ce que vous demandez.

## Installer l'APK (hors Play Store)

1. Téléchargez le fichier APK depuis les **[Releases](https://github.com/victordiaz1000/bym-classic/releases)**.
2. Chrome avertit « fichier potentiellement dangereux » : choisissez
   **« Télécharger quand même »** — l'APK vient de GitHub.
3. Ouvrez le fichier téléchargé ; Android demande d'autoriser l'installation
   depuis votre navigateur : activez **« Autoriser cette source »**.
4. Validez. *Bym classic* apparaît dans vos applications.

L'APK est signé avec la clé de release de l'auteur : les mises à jour
s'installent par-dessus l'ancienne version **sans perte de données** (notes,
favoris et surlignages vivent dans la base locale de l'appareil).

## Développement

Application **Flutter** (Dart ≥ 3.12), cible Android (`com.bym.bible_app`),
architecture classique `lib/data` · `lib/models` · `lib/screens` ·
`lib/widgets`.

```bash
flutter pub get        # dépendances
flutter run            # exécution sur appareil / émulateur
flutter build apk --release            # APK de release
flutter build apk --release --split-per-abi   # APK plus léger par ABI
flutter test           # suite de tests
```

- **Tests** — plus de 100 fichiers de tests : intégrité des données BYM,
  formats ATI / NTI / SES / LSGS, moteur de recherche, onglets, notes,
  thèmes, rendu des polices, mises à jour du texte, écrans.
- **Signature de release** — `android/key.properties` (ignoré par git) lit le
  keystore décrit dans `android/key.properties.example` ; sans lui, le build
  annonce qu'il produit une version signée en debug.
- **Publication** — pousser un tag `v*` déclenche le workflow
  `.github/workflows/release-apk.yml`, qui construit l'APK et prépare la
  release GitHub :

  ```bash
  git tag v1.1.0
  git push origin v1.1.0
  ```
