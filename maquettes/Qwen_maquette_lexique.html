Le lexique, à fleur de mot

Le lexique ne vit pas dans un coin de l'application : il se déclenche là où le lecteur lit. Un mot annoté, touché en pleine lecture, ouvre la fiche — et la fiche s'ouvre dans un onglet, comme toute étude (§ 3.3). Démonstration avec votre note sur « humain » (אָדָם) en Genèse 1:26.

01

Du mot à la fiche, en deux gestes

La démo suit le parcours réel : lecture annotée de Genèse 1.26 → toucher du mot humain → fiche de mot → ouverture de l'écran Lexique dans un nouvel onglet.

  • Touchez le mot « humain » (souligné pointillé doré, v. 26) : la fiche de mot remonte, nourrie de votre note de traduction § 2.2
  • « Ouvrir dans le lexique ↗ » : l'écran complet s'ouvre dans un nouvel onglet — le compteur passe de 2 à 3 § 3.3
  • Dans le lexique : définition, équivalent grec, termes proches (אָדָם / 'Âdâm / 'îysh — vos trois distinctions)
  • Les occurrences citées par votre note (Ge 1.26-27, 2.7, 3.8-9, 4.1…) s'ouvrent chacune dans un onglet au toucher
  • « Voir la note de Ge. 1.26 » ramène à la lecture et illumine la note d'origine
  • En mode Texte seul, les mots ne sont pas interactifs : le lexique ne se déclenche qu'en lecture annotée

Définition

« Être humain », « de la terre ». Littéralement « le terreux, le glaiseux » : formé à partir de ha-adamah, « la terre, la glaise » — jeu de mots étymologique analogue au latin homo / humus (Ge. 2.7). Terme le plus fréquemment employé dans le Tanakh ; désigne le genre humain dans sa globalité.

02

Quand le lexique se déclenche-t-il ?

Cinq portes d'entrée, une seule destination : la fiche de mot. Le déclencheur principal reste le texte lui-même.

1 Mot annoté dans la lecture — déclencheur principal

En mode Texte + notes, chaque mot porteur d'une note est souligné en pointillé doré. Un toucher ouvre la fiche de mot, puis l'écran Lexique complet dans un onglet. En mode Texte seul, aucun déclenchement.

 § 2.2 · 3.1
2 Terme hébreu / grec cité dans une note

Les termes entre crochets de vos notes — ['âdâm], ['îysh], tohuw, bohuw, neged… — deviennent des liens : toucher le terme ouvre sa fiche lexique.

 § 2.2
3 Recherche unifiée

Les entrées du lexique apparaissent dans les résultats de recherche (§ 3.2) : par mot hébreu ou grec, translittération (« ro'eh »), sens (« berger ») ou référence Strong (H7462).

 § 3.2
4 Bibliothèque — parcours libre

Depuis la Bibliothèque, après téléchargement du « Lexique hébreu — Strong » ou « Lexique grec — Strong » (18 / 16 Mo, à la demande), le lecteur peut parcourir l'index alphabétique et chercher librement.

 § 2.2
5 De fiche en fiche

Depuis une fiche : équivalent grec, termes proches, occurrences cliquables et références croisées — chaque lien s'ouvre dans un onglet, sans fermer l'étude en cours.

 § 3.3
⛭

Sans lexique téléchargé (§ 2.2, tout est optionnel) : le mot annoté ouvre uniquement la note de Victor, qui reste pleinement lisible ; un bouton discret « Télécharger le lexique hébreu (18 Mo) » mène à la Bibliothèque. Aucune fonction n'est bloquée — la fiche enrichie est une augmentation, jamais un prérequis.

03

Structure proposée & pont avec votre fichier

Le lexique est un module séparé (téléchargeable), relié à vos notes par une simple référence. Votre fichier 01-Genese.json n'a presque rien à changer.

lexique-hebreu.json — module (style Strong) { "module": "lexique-hebreu-strong", "version": "1.0", "entrees": [ { "id": "H120", "mot": "אָדָם", // rendu RTL (right-to-left) "translitteration": "'âdâm", "phonetique": "aw-dawm'", "type": "nom masculin", "definition": "être humain, humanité — littéralement « le terreux, le glaiseux »", "grec": "G444", // équivalent grec (module grec) "proches": ["H121", "H376", "H127"], // 'Âdâm, 'îysh, ha-adamah "occurrences": [ { "ref": "Ge. 1:26", "contexte": "Nous ferons l'être humain à notre image…" }, { "ref": "Ge. 2:7", "contexte": "YHWH Elohîm forma l'être humain à partir de la poussière du sol…" } ] } ] }
Le pont avec votre 01-Genese.json
  • Vos objets notes[] gagnent une clé facultative : "lexique": "H120" sur la note de « humain » (Ge. 1:26) — c'est le seul ajout nécessaire.
  • Sans cette clé, l'appareil détecte les termes entre crochets de vos notes (['âdâm], ['îysh]…) et les relie par translittération.
  • Sans module téléchargé : la note s'affiche seule, un bouton propose le téléchargement (§ 2.2).
  • textWithNotes reste facultatif : l'interface régénère l'affichage depuis text + notes[].
Règles de rendu
  • Hébreu en RTL : la fiche passe le mot en écriture droite-à-gauche, le reste de l'écran reste en LTR.
  • Police dédiée hébreu/grec (Noto Serif Hebrew ou fournie avec le module), taille 44–54 px pour la vedette.
  • Ancrage par position : le mot est repéré à l'index caractère, avec repli sur la recherche du mot (§ déjà vu v4).
  • Fiche = onglet : toute ouverture de lexique crée ou réactive un onglet (§ 3.3), mémorisé localement.
  • Recherche du module indexée dans la recherche unifiée (§ 3.2) : mot, translittération, Strong, sens.
