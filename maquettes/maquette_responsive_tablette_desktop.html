06 Spec Flutter — quoi changer, concrètement

Pas de refonte. 5 interventions, dans l'ordre de rentabilité :

1) lib/utils/breakpoints.dart (NOUVEAU — source unique) const kTablet = 600, kExpanded = 840, kDesktop = 1200, kMaxNarrow = 720, kMaxWide = 1120; 2) main.dart — _BymShell.build - Row(Rail, Expanded(Center(ConstrainedBox(maxWidth: isDesktop?1120:720, child: content)))) - extended: width >= 840 (inchangé) 3) widgets/centered_column.dart (NOUVEAU) - utilisé par Home, Search, Library, Settings, Notes, Favoris 4) chapter_reader.dart — Lecture ≥1200 - Row(Expanded(versets 65ch), SizedBox(340, child: fiche Strong/note)) - si pas de fiche ouverte : versets seuls centrés - garder bar-actions ≥600 telles quelles 5) search / parallel / lexique ≥840 - SearchScreen: Row(300px filtres, Expanded(résultats)) - ParallelReadingScreen: proposé par défaut en paysage ≥840 (bouton ⇄ déjà là) - Strong/Lexique: Row(index, fiche) au lieu de push plein écran Tests: étendre responsive_overflow_test.dart avec '1280x800 desktop' + vérifier aucun RenderFlex overflow à x1.0 / x2.0 (borne 1.18 déjà là).
  • Gain immédiat : 2) + 3) seuls règlent 80% du problème tablette (lignes trop longues, hero géant).
  • Sans régression phone : aucun changement sous 600px — les tests 320 / 360 / 390 restent verts.
  • Accessibilité : ne pas toucher à ResponsiveTextScaling.maxScaleFactor = 1.18 ni au deviceFactor.
