Points ouverts — recommandations techniques

Stack proposée (§ 4 & 5)

  • React Native (Expo) en premier choix : un seul code pour Android + iOS, rendu natif et contrôle typographique fin — la priorité visuelle du cahier des charges. Flutter reste écarté, conformément au § 4.
  • SQLite embarqué pour le texte biblique, les lexiques Strong et les données locales (notes, surlignages, favoris, onglets) — socle du mode hors-ligne.
  • Filebase pour la synchronisation cloud optionnelle (§ 3.7) : objet simple, aucune donnée utilisateur par défaut.
  • Audio : TTS via moteur natif (AVSpeechSynthesizer / Android TTS), voix humaines en flux MP3 — streaming uniquement (§ 3.1).

Rappels du périmètre

  • 100 % gratuite, sans version premium, sans publicité.
  • Français uniquement dans cette version.
  • Pas de plans de lecture — hors périmètre v1.
  • Notifications limitées aux nouveautés (§ 3.8).
  • Images de fond des thèmes fournies par Victor ; la maquette les simule fidèlement.
